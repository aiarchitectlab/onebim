# OneBIM by AI ARCH LAB

**OneBIM คือโปรแกรม BIM ภาษาไทยที่ทำงานบนมาตรฐาน IFC**

OneBIM เป็นโปรแกรมเขียนแบบและสร้างแบบจำลองอาคาร (BIM) สำหรับสถาปนิก วิศวกร และนักออกแบบ
หน้าจอทั้งหมดเป็นภาษาไทย บันทึกและเปิดไฟล์ IFC ได้โดยตรง จึงส่งงานต่อให้โปรแกรม BIM อื่นได้

OneBIM พัฒนาต่อจาก [Lapin](https://github.com/Ciuntuc-BIM-Studio/lapin) ของ Ciuntuc BIM Studio
ซึ่งเป็นโปรแกรมโอเพนซอร์สภายใต้สัญญาอนุญาต MIT

## ทำอะไรได้บ้าง

- **สถาปัตยกรรม:** ผนัง พื้น หลังคา ประตู หน้าต่าง บันได ราว ห้อง เฟอร์นิเจอร์ ระเบียง ลิฟต์
- **แบบก่อสร้าง:** แปลน รูปตัด รูปด้าน แบบขยาย แผ่นแบบพร้อมกรอบชื่อแบบ ป้าย ระยะ แฮทช์
- **ตาราง:** ตารางประตูหน้าต่าง ตารางห้อง ตารางปริมาณวัสดุ ประมาณราคา
- **โครงสร้าง:** เสา คาน ฐานราก เหล็กเสริม โครงเหล็ก และการวิเคราะห์โครงสร้างเบื้องต้น
  (ผลเป็นค่าประมาณ ต้องให้วิศวกรตรวจทุกครั้ง)
- **งานภายนอก:** ภูมิประเทศ ถนน ทางเดิน การปรับระดับดิน Point cloud
- **ส่งออก:** IFC, PDF, DXF, รูปภาพ และไฟล์ .html ที่เปิดดูแบบ 3D ในเบราว์เซอร์ได้

## ดาวน์โหลดและติดตั้ง (Windows)

1. ไปที่หน้า [Releases](https://github.com/aiarchitectlab/onebim/releases) แล้วเลือกเวอร์ชันล่าสุด
2. ดาวน์โหลดไฟล์ใดไฟล์หนึ่ง:
   - `OneBIM_..._x64-setup.exe` ตัวติดตั้ง ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ
   - `OneBIM_..._x64-portable.zip` แตกไฟล์แล้วเปิด `OneBIM.exe` ได้เลย ไม่ต้องติดตั้ง
3. ไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล ตอนเปิดครั้งแรก Windows อาจขึ้นหน้าต่าง SmartScreen
   ให้กด **More info → Run anyway**

## ข้อจำกัดที่ควรรู้

- ถ้าส่งออก PDF จากเมนูของโปรแกรม ตัวอักษรไทยอาจแสดงไม่ถูกต้อง
  ระหว่างนี้ให้ใช้ **พิมพ์ → บันทึกเป็น PDF** แทน
- คู่มือการใช้งานยังเป็นภาษาอังกฤษ (ของ Lapin)
- ค่ามาตรฐานในเครื่องมือโครงสร้างอ้างอิง Eurocode ไม่ใช่มาตรฐานไทย ใช้เพื่อประมาณการเบื้องต้นเท่านั้น

## สร้างโปรแกรมเอง (สำหรับนักพัฒนา)

ต้องติดตั้ง Node.js 22, pnpm, .NET 10 SDK และ Rust ก่อน แล้วรัน:

```sh
pnpm install
pnpm build:product onebim
```

ไฟล์ที่ได้จะอยู่ใน `build/onebim/bundle/`

ถ้าไม่อยากสร้างเอง ให้ใช้ GitHub Actions ของ repo นี้ คือ **Build Windows** และ **Build Linux**
ซึ่งจะทำงานเมื่อ push tag `v*` หรือกดสั่งเองจากแท็บ Actions

รายละเอียดทางเทคนิคของโครงสร้างโค้ดดูได้ที่ [README.lapin.md](README.lapin.md) (ภาษาอังกฤษ จาก Lapin)
